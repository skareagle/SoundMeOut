Decodable Reader — build spec

A local reading-practice app for one child. Generates fresh decodable stories so the text rotates instead of being memorised, and presents them in a UI built for sounding out rather than guessing.

A working prototype of the UI is included as Appendix B. Treat it as the interaction reference, not the architecture — it is a single static file with five hardcoded stories. The build replaces the story source and adds progress tracking, keeping the reading surface close to what the prototype does.

1. The one requirement that matters

Every content word in a generated story must be decodable using only the graphemes taught at or before the current step, plus an explicit list of heart words.

This is not a soft goal. A single untaught word — beautiful, through, light — breaks the entire premise, because the child then either guesses or is told the word, which is the habit the app exists to prevent. The parent cannot pre-read every story.

An LLM asked to "write a decodable story using short vowels" will produce untaught patterns in roughly every generation. Assume this. The system must therefore be generate-then-verify, and text that fails verification is never displayed.

Two layers:

  1. Constrain generation. The model is given a word bank and instructed to use only words from it. This is arrangement, not invention.
  2. Verify mechanically. A validator checks every word against the allowed set. Any failure rejects the whole story and regenerates. No partial acceptance, no auto-repair by substitution.

If the validator and the generator ever disagree, the validator wins.

2. Data model

Scope sequence

The phonics progression. Each step is cumulative — step 4 permits everything from steps 1–3.

{
  "id": 4,
  "tag": "Step 4",
  "name": "blends",
  "teaches": ["initial and final consonant blends"],
  "graphemes_added": [],
  "structures_added": ["CCVC", "CVCC", "CCVCC"],
  "heart_words": ["the", "a", "to"],
  "word_bank": ["stop", "step", "spin", "slip", "clap", "flag", "grab", "..."]
}

Steps 1–5 as built in the prototype:

Step Name Adds
1 short a a + common consonants, CVC only
2 all short vowels e i o u
3 digraphs sh ch th ck wh
4 blends consonant clusters, no new graphemes
5 magic e split digraphs a_e i_e o_e u_e

Extend with these — the child will need them within months, and the architecture should not have to change to accommodate them:

Step Name Adds
6 vowel teams I ai ay ee ea
7 vowel teams II oa ow oo
8 r-controlled ar or er ir ur
9 diphthongs oi oy ou ow
10 common endings -ing -ed -s -es, -le syllables

Steps 6+ introduce ambiguity (ea says two things, ow says two things). The grapheme splitter must handle a grapheme mapping to multiple sounds — store the sound as part of the word-bank entry rather than deriving it, e.g. {"w": "bread", "sounds": ["b", "r", "ea:short-e", "d"]}.

Word bank

The word bank is the source of truth and the thing worth investing in. Per step, a curated list of words that are decodable at that step and meaningful to a six-year-old.

Recommended: store each entry with its graphemes pre-segmented rather than deriving them at runtime. Derivation works for steps 1–5 (see the splitter in Appendix B) and breaks down after that. Pre-segmenting also gives you a free correctness check when adding words.

{ "w": "ship", "g": [["sh","d"],["i","v"],["p","c"]], "step": 3 }

Grapheme kinds: c consonant, v vowel, d digraph, s silent, t vowel team.

Story

3. Architecture

Keep the reading surface offline and instant. Generation happens ahead of time, not while the child waits.

/stories/
  step-1.json          pool of validated stories
  step-2.json
  ...
/data/
  word-banks.json
  scope-sequence.json
  progress.json
/scripts/
  generate.js          calls the API, validates, appends to pool
  validate.js          standalone validator, also used by generate
index.html             the reading app — reads JSON, no network

npm run generate -- --step 3 --count 10 tops up a pool. The app itself never calls an API, never blocks on one, and works on a tablet in airplane mode.

Anthropic API via @anthropic-ai/sdk, key from env. Model: claude-sonnet-4-6 is ample for this.

Generation prompt shape

You are writing a decodable story for a 6-year-old at phonics step {step} ({name}).

You may use ONLY these words:
{word_bank joined}

Plus these heart words: {heart_words}

Rules:
- 6 to 9 sentences, 3 to 7 words each.
- It must be an actual story: something happens, and it ends.
- Proper names allowed only if decodable at this step (Sam, Jack, Jake).
- No word outside the lists above. Not one.
- Vary sentence openings; do not start every line with "The".

Return JSON: { "title": string, "lines": string[] }

Then: parse, validate, discard and retry on failure (cap at ~5 attempts, log the rejects — the reject log tells you which words the model keeps reaching for and is the best signal for what to add to the bank).

Validator

for each line:
  for each token:
    word = strip punctuation, lowercase
    if word is empty: continue
    if word in heart_words[step]: ok
    if word in union(word_bank[1..step]): ok
    else: REJECT(word)

Deliberately dumb and deliberately strict. No stemming, no "close enough". If digs should be legal, digs goes in the bank.

Also reject on: fewer than 5 lines, any line over 9 words, duplicate lines, a line with no verb-bearing structure (cheap heuristic: reject if the story's distinct word count is under 60% of total word count — catches the degenerate repetitive output the model falls into when the bank is small).

4. The reading app

Appendix B is the reference. Port the interaction model; improve the plumbing.

Keep exactly as-is

  • No images, anywhere. The absence is the design. Do not add illustrations, mascots, or decorative art to the reading surface.
  • Tap a word → sound breakdown. Graphemes split with separators, coloured by kind, plus /sh/ /i/ /p/ → ship. Silent e greyed with a one-line explanation.
  • Heart words visually distinct (purple in the prototype) and excluded from segmentation. Tapping one says "just tell him the word" rather than attempting a breakdown.
  • Warm-up strip of words above the story, tappable, same segmentation.
  • "Colour the sounds" toggle — off by default, so the default reading experience is plain black text.
  • "One line at a time" — dims all but the current line, arrow keys advance.
  • Repeated-reading dots — three, for the same story across three days.
  • Print — controls drop away, large type, clean page.
  • Type: Andika (single-storey a and g, designed for literacy). Keep the fallback stack.

Add

  • Stumble log. During reading, a long-press or a dedicated toggle marks a word the child struggled with. Marked words go into progress.stumbles and are injected into tomorrow's warm-up strip. This is the highest-value addition — it turns the app into something that adapts.
  • Story rotation. Serve an unseen story from the current step's pool. When the pool is exhausted, either regenerate or cycle oldest-first. Never serve the same story twice in a row, and never serve a story the child has read 3× until everything else has been through once.
  • Step promotion, manual. A parent control, not automatic. Show a readiness hint — "8 stories at step 2, 3 reads each, stumbles down from 11 to 2" — and let the adult decide. Automatic promotion on a metric will push him forward before he's solid, which is the main way these apps do harm.
  • Session view. After reading: which words were marked, how many, trend across the last five sessions. One screen, for the parent, at the end.

Do not add

  • Any "what do you think happens next?" or picture-cue prompt.
  • Text-to-speech that pronounces a whole word on tap. It removes the exact effort the app exists to create. A parent-gated "say it" button after a failed attempt is acceptable; automatic is not.
  • Timers, scores, streaks, confetti. A struggling reader does not need to be told he was slow.
  • Difficulty auto-adjustment inside a step.

5. Acceptance

The build is done when:

  1. Generating 100 stories at each of steps 1–5 yields zero validator failures in the served pool, and the reject rate is logged.
  2. A deliberately poisoned story (inject through into a step-2 story JSON) is refused at load time, not just at generation time. Validate on read as well as on write.
  3. The app loads and runs with the network disabled.
  4. Every word in a served story can be tapped and produces a correct grapheme split. Spot-check the full vocabulary of one step by hand — the splitter is where silent bugs live.
  5. Print output of any story is legible at arm's length on paper.
  6. progress.json survives a browser restart, and deleting it degrades gracefully to a fresh start rather than crashing.

6. Notes on the reader this is for

The intended reader is an early reader who is learning to decode. This is practice, not remediation — build accordingly. Start every new reader at step 1 regardless of level; the value of an easy first session is high and the cost is ten minutes.

Expected use is about ten minutes a day, the child reading aloud to an adult, followed by about twenty minutes of the adult reading real books aloud, well above the child's own level. The app covers the first ten minutes only. Nothing in it should imply it covers the rest.

Appendix A — grapheme splitter (steps 1–5)

Works to step 5. Replace with a table-driven splitter, or pre-segmented bank entries, before adding vowel teams.

var DIGRAPHS = ["sh","ch","th","ck","wh","ph","ng","nk","qu"];
var VOWELS = "aeiou";

function graphemes(word){
  var w = word.toLowerCase().replace(/[^a-z]/g,"");
  var silentE = false;
  if (w.length >= 4 && w.charAt(w.length-1) === "e"){
    var c = w.charAt(w.length-2), v = w.charAt(w.length-3);
    if (VOWELS.indexOf(c) === -1 && VOWELS.indexOf(v) !== -1) silentE = true;
  }
  var body = silentE ? w.slice(0,-1) : w;
  var out = [], i = 0;
  while (i < body.length){
    var pair = body.substr(i,2), hit = false;
    for (var d = 0; d < DIGRAPHS.length; d++){
      if (pair === DIGRAPHS[d]){ out.push({t:pair,k:"d"}); i += 2; hit = true; break; }
    }
    if (hit) continue;
    var ch = body.charAt(i);
    out.push({t:ch, k: VOWELS.indexOf(ch) !== -1 ? "v" : "c"});
    i++;
  }
  if (silentE) out.push({t:"e", k:"s"});
  return out;
}

Known limits: has and is end in /z/ and are reported as /s/. ng/nk are treated as digraphs everywhere, which is right for sing and wrong for ungag. Neither matters inside a curated bank; both matter if you ever run the splitter on arbitrary input.

/* ---- split a word into graphemes ---- */
var DIGRAPHS = ["sh","ch","th","ck","wh","ph","ng","nk","qu"];
var VOWELS = "aeiou";

function graphemes(word){
  var w = word.toLowerCase().replace(/[^a-z]/g,"");
  var silentE = false;
  // magic e: ends in e, preceded by consonant, preceded by a vowel, word >= 4 letters
  if (w.length >= 4 && w.charAt(w.length-1) === "e"){
    var c = w.charAt(w.length-2), v = w.charAt(w.length-3);
    if (VOWELS.indexOf(c) === -1 && VOWELS.indexOf(v) !== -1) silentE = true;
  }
  var body = silentE ? w.slice(0, -1) : w;
  var out = [], i = 0;
  while (i < body.length){
    var pair = body.substr(i,2), hit = false;
    for (var d = 0; d < DIGRAPHS.length; d++){
      if (pair === DIGRAPHS[d]){ out.push({t:pair, k:"d"}); i += 2; hit = true; break; }
    }
    if (hit) continue;
    var ch = body.charAt(i);
    out.push({t:ch, k: VOWELS.indexOf(ch) !== -1 ? "v" : "c"});
    i++;
  }
  if (silentE) out.push({t:"e", k:"s"});
  return out;
}

function isHeart(word, stepHeart){
  var w = word.toLowerCase().replace(/[^a-z]/g,"");
  if (!w) return false;
  if (HEART.indexOf(w) !== -1) return true;
  return stepHeart.some(function(h){ return h.toLowerCase() === w; }) && HEART.indexOf(w) !== -1;
}

/* ---- storage (best effort) ---- */
function repsGet(i){
  try {
    var v = window.localStorage.getItem("soundout:reps:" + i);
    return v ? parseInt(v,10) || 0 : 0;
  } catch(e){ return 0; }
}
function repsSet(i,n){
  try { window.localStorage.setItem("soundout:reps:" + i, String(n)); } catch(e){}
}

/* ---- tray ---- */
function showSounds(word){
  var clean = word.replace(/[^A-Za-z]/g,"");
  if (!clean) return;
  var heartWord = HEART.indexOf(clean.toLowerCase()) !== -1;
  var html = "";
  if (heartWord){
    html = '<div class="tray-graph"><span class="g" style="color:var(--heart)">' + clean + '</span></div>' +
           '<p class="tray-say">A heart word. Just tell him: <strong>' + clean.toLowerCase() + '</strong>. It doesn\'t follow the rules yet.</p>';
  } else {
    var gs = graphemes(clean), parts = [], says = [];
    for (var i = 0; i < gs.length; i++){
      parts.push('<span class="g ' + gs[i].k + '">' + gs[i].t + '</span>');
      if (gs[i].k !== "s") says.push("/" + gs[i].t + "/");
    }
    html = '<div class="tray-graph">' + parts.join('<span class="sep">&#183;</span>') + '</div>' +
           '<p class="tray-say">' + says.join(" ") + ' &rarr; <strong>' + clean.toLowerCase() + '</strong>' +
           (gs[gs.length-1].k === "s" ? ' &nbsp;· the <b>e</b> is silent — it makes the vowel say its name.' : '') +
           '</p>';
  }
  elTray.innerHTML = html;
}

function clearPicked(){
  var ps = document.querySelectorAll(".w.picked, .chip.picked");
  for (var i = 0; i < ps.length; i++) ps[i].classList.remove("picked");
}

/* ---- render ---- */
function renderChips(){
  var s = STEPS[current];
  elWarm.innerHTML = "";
  s.warmup.forEach(function(w){
    var b = document.createElement("button");
    b.className = "chip"; b.type = "button"; b.textContent = w;
    b.addEventListener("click", function(){ clearPicked(); b.classList.add("picked"); showSounds(w); });
    elWarm.appendChild(b);
  });
  elHeart.innerHTML = "";
  s.heart.forEach(function(w){
    var b = document.createElement("span");
    b.className = "chip heart"; b.textContent = w;
    elHeart.appendChild(b);
  });
}

function renderStory(){
  var s = STEPS[current];
  elStory.innerHTML = "";
  s.lines.forEach(function(line, li){
    var p = document.createElement("p");
    p.className = "line";
    if (li === 0) p.classList.add("on");
    line.split(" ").forEach(function(tok, ti){
      if (ti) p.appendChild(document.createTextNode(" "));
      var core = tok.replace(/[^A-Za-z]/g,"");
      if (!core){ p.appendChild(document.createTextNode(tok)); return; }
      var lead = tok.slice(0, tok.indexOf(core.charAt(0)));
      var tail = tok.slice(tok.indexOf(core.charAt(0)) + core.length);
      if (lead) p.appendChild(document.createTextNode(lead));
      var span = document.createElement("span");
      span.className = "w";
      if (HEART.indexOf(core.toLowerCase()) !== -1){
        span.classList.add("heartword");
        span.textContent = core;
      } else {
        var gs = graphemes(core), used = 0;
        gs.forEach(function(g){
          var seg = document.createElement("span");
          seg.className = g.k;
          seg.textContent = core.substr(used, g.t.length);
          used += g.t.length;
          span.appendChild(seg);
        });
      }
      span.addEventListener("click", function(){ clearPicked(); span.classList.add("picked"); showSounds(core); });
      p.appendChild(span);
      if (tail) p.appendChild(document.createTextNode(tail));
    });
    elStory.appendChild(p);
  });
  lineIdx = 0;
  applyPacing();
}

function renderDots(){
  var n = repsGet(current);
  elDots.innerHTML = "";
  for (var i = 0; i < 3; i++){
    (function(k){
      var d = document.createElement("button");
      d.className = "dot"; d.type = "button";
      d.setAttribute("data-on", k < n ? "1" : "0");
      d.setAttribute("aria-label", "Read-through " + (k+1));
      d.addEventListener("click", function(){
        var cur = repsGet(current);
        repsSet(current, cur === k + 1 ? k : k + 1);
        renderDots();
      });
      elDots.appendChild(d);
    })(i);
  }
}

function applyPacing(){
  var lines = elStory.querySelectorAll(".line");
  elStory.classList.toggle("paced", paced);
  elPacer.classList.toggle("on", paced);
  for (var i = 0; i < lines.length; i++) lines[i].classList.toggle("on", i === lineIdx);
  elCount.textContent = paced ? (lineIdx + 1) + " of " + lines.length : "";
}

function move(delta){
  var total = STEPS[current].lines.length;
  lineIdx = Math.max(0, Math.min(total - 1, lineIdx + delta));
  applyPacing();
}

function select(i){
  current = i;
  var btns = elSteps.querySelectorAll(".step-btn");
  for (var k = 0; k < btns.length; k++) btns[k].setAttribute("aria-selected", k === i ? "true" : "false");
  elTray.innerHTML = '<p class="empty">Tap any word above or in the story to see its sounds.</p>';
  renderChips(); renderStory(); renderDots();
}
